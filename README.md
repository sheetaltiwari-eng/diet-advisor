# Smart Diet Advisor

Personalized dietary guidance based on individual health requirements.

## Features
- **Health Assessment**: Input age, gender, height, weight, and activity level.
- **Personalized Recommendations**: Get diet plans based on your goals (Weight Loss, Muscle Gain, Wellness).
- **Dashboard**: Track your calories, water intake, and daily meals.
- **Expert Chat**: Interact with nutrition experts for real-time guidance.
- **Modern UI**: Dark mode, glassmorphism, and responsive design.

## How to Run
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Build for production: `npm run build`

## Project Structure
- `src/components`: UI components (Navbar, etc.)
- `src/pages`: Main application views (Home, Assessment, Dashboard, Chat)
- `src/styles`: Global CSS and design tokens
